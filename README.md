# CountyEdu 🎓

CountyEdu is a career-focused educational platform designed to help learners explore and choose programs across **technology and non-technology domains**.

The website provides career-oriented programs, combo career paths, pricing information, learner testimonials, FAQs, and other resources to help students make informed decisions about their career growth.

---

## 🌐 Project Overview

CountyEdu provides a modern and responsive interface where learners can:

* Explore technology programs
* Explore non-technology programs
* Browse career-focused combo programs
* View individual program details
* Explore pricing plans
* Read learner testimonials
* View frequently asked questions
* Discover different career paths
* Explore programs based on their interests

---

## ✨ Features

### 📚 Programs

Explore multiple career-oriented programs across technology and non-technology domains.

### 🚀 Career Combos

Career combo programs combine multiple skills and technologies into structured career paths.

### 💰 Pricing

Dedicated pricing sections allow users to explore available plans and program offerings.

### ⭐ Student Testimonials

The website includes testimonials from learners who have completed or experienced the programs.

### 🔍 Program Discovery

Users can explore and filter available programs based on different categories.

### ❓ FAQ Section

Frequently asked questions provide users with additional information about programs and services.

### 📱 Responsive Design

The website is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile devices

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Countyedu.git
```

### 2. Navigate to the Project

```bash
cd Countyedu
```

### 3. Run the Website

CountyEdu is a static HTML, CSS, and JavaScript website, so no backend installation or package manager is required.

Simply open:

```text
index.html
```

in your browser.

For development, you can also use the **Live Server** extension in Visual Studio Code.

---

## 💻 Local Development

If you are using VS Code:

1. Open the `Countyedu` folder.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.
5. The website will open in your browser.

---

## 🌍 Deployment

CountyEdu can be deployed using **GitHub Pages**.

### GitHub Pages Steps

1. Open your GitHub repository.
2. Go to **Settings**.
3. Select **Pages**.
4. Under **Build and deployment**, select:

   * **Source:** Deploy from a branch
   * **Branch:** `main`
   * **Folder:** `/ (root)`
5. Click **Save**.

GitHub will generate a public website URL for your project.
